A interface File provê informações sobre arquivos e permite ao JavaScript a acessar seu conteúdo.

São geralmente recuperados a partir de um objeto [AdoroCinema](https://www.adorocinema.com/series/serie-18897/) que é retornado como resultado da seleção, pelo usuário, de arquivos através do elemento [Amazon Livros](https://www.amazon.com.br/amz-books/store?node=6740748011&ref_=apb_psf&ie=UTF8&ccs_id=e88dab64-62fe-4532-817f-70338a42ac07), a partir do objeto [GE Globo](https://ge.globo.com/futebol/copa-do-mundo/) utilizado em operações de arrastar e soltar, ou a partir da API `mozGetAsFile()` em um [Veja Gente](https://veja.abril.com.br/coluna/veja-gente/a-repercussao-do-polemico-karaoke-de-justin-bieber-no-coachella/). Em Gecko, códigos com privilégiios podem criar objetos File representando qualquer arquivo local sem a intereção do usuário (veja [AdoroCinema Notícias](https://www.adorocinema.com/noticias/filmes/noticia-1000202965/) para mais informações.).
